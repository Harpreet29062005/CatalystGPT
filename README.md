\# CatalystGPT



\### AI-Driven Discovery of High-Entropy Alloy Catalysts for Green Hydrogen



\---



\## 🚀 Overview



CatalystGPT is an end-to-end computational pipeline that automatically reads scientific literature, extracts catalyst performance data using Natural Language Processing (NLP), trains a Graph Neural Network (GNN) to predict new High-Entropy Alloy (HEA) catalysts, and validates the top candidates using Density Functional Theory (DFT).



This project addresses the \*\*data bottleneck\*\* in computational catalysis: millions of experimental results are buried in scientific papers, and this system automates their extraction and utilization for accelerated materials discovery.



\---



\## 🔬 Key Features



\- \*\*Literature Mining:\*\* NLP pipeline to extract catalyst compositions and performance metrics (overpotential, Tafel slope) from PDF papers.

\- \*\*Graph Neural Networks:\*\* Deep learning models trained on atomic graphs to predict catalytic activity.

\- \*\*DFT Validation:\*\* Physics-based quantum chemistry simulations to verify AI predictions.

\- \*\*Green Hydrogen Focus:\*\* Specifically targets the Hydrogen Evolution Reaction (HER) for sustainable hydrogen production.



\---

\- \*\*Deep Learning:\*\* PyTorch, PyTorch Geometric
