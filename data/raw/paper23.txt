Machine-LearningModelsforEnergyPrediction
To accelerate the large number of energy evaluations required to explore the compositional space of HEA nan-
oclusters,weemployedaML-basedsurrogatemodel.Themodelarchitecture,trainingprocedures,andcomprehensive
performanceevaluationshavebeenreportedinourpreviouswork[26].Here,wesummarizethefeaturesandpredictive
performancemostrelevanttothepresentstudy.
The surrogate model is based on the Bond-type Embedded Orbital Graph Convolutional Neural Network (BE-
OGCNN) architecture. A key feature of this architecture is its distance-insensitive representation, which enables
efficient screening without requiring fully relaxed geometries for every candidate structure. Rather than using
explicit interatomic-distance or bond-angle descriptors, BE-OGCNN represents each structure through its nearest-
neighborconnectivitygraphandorbital-interactionfeatures.Thisrepresentationcaptureschemicallyrelevantbonding
informationfromtheelementalidentitiesandlocalconnectivityoftheconstituentatoms.

S1.MachineLearningModelOverview
The predictive model developed in this study is an enhanced distance-insensitive graph neural network named
theBond-typeEmbeddedOrbitalGraphConvolutionalNeuralNetwork(BE-OGCNN).BuiltupontheBE-CGCNN
framework[1],thismodelisdesignedtorelysolelyontheconnectivitygraphofnearest-neighboratoms,bypassing
theneedforprecisegeometricinputssuchasbondlengthsandangles.Tomaximizeexpressivitywithoutgeometric
dependency,theBE-OGCNNintegratesorbitalinteractionfeatures.
Furthermore, the model employs a hard parameter sharing Multi-Task Learning (MTL) framework to improve
dataefficiencyandgeneralization.Theprimarytaskisthepredictionofhydrogenadsorptionenergy,whilethed-band
centerandtotalstructuralenergyserveasauxiliarytasks.

S4.StabilityComparison:Octahedralvs.TruncatedOctahedralClusters
Acommonlyraisedquestionregardingthechoiceofclustergeometryiswhethertheregularoctahedralstructure

The DFT calculations were performed using the Vienna Ab initio Simulation Package (VASP)[4], employing
thePerdew-Burke-Ernzerhof(PBE)[5]exchange-correlationfunctionalandtheprojector-augmented-wave(PAW)[6]
method. A plane-wave energy cut-off of 500 eV was used. Brillouin-zone integrations were performed using
Monkhorst-Pack k-point sampling[7], with 3×3×3 grids for the four-layer (44-atom) models and 1×1×1 grids
forthefive-layer(85-atom)models.Avacuumspacingofatleast15Å wasintroducedtoavoidinteractionsbetween
periodicimages.Theelectronicconvergencecriterionwassetto10−4eV,andtheatomicconfigurationswererelaxed
untiltheatomicforceswerebelow0.01eV/Å.
